## Why

A prior session had already produced a substantial `docs/auth/ARCHITECTURE.md`
(decisions, flowcharts, component map, threat model, env inventory, decision log, open
questions) under a different, 15-phase numbering. Rather than discard that work
(AUTH_RULES.md rule 7: prefer the smallest safe change, preserve existing intended
behavior), this phase audited it against the current instruction set's exact
deliverables, found it already satisfied most of them, and added only what was
genuinely missing (project layout, data connection diagram, sequence-diagram-style
flows, and a per-checklist-item "Planned" component inventory) rather than rewriting
what was already correct.
